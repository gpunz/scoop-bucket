# gpu.nz Scoop bucket

[Scoop](https://scoop.sh) manifest for [gpunz](https://github.com/gpunz/gpunz-cli), the command-line client of the [gpu.nz](https://gpu.nz) GPU cloud.

```powershell
scoop bucket add gpunz https://github.com/gpunz/scoop-bucket
scoop install gpunz
gpunz login
```

Windows x64 and arm64. Other ways to install: [gpu.nz/docs/cli](https://gpu.nz/en/docs/cli).
